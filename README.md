# Summer Blooms Website

Summer Blooms is a responsive handmade floral shop website built using HTML and CSS. It showcases fuzzy wire and satin ribbon flower arrangements with a modern, clean online shop layout.

---

## 🌸 Features

- Multi-page website (Home, About, Shop, Contact)
- Responsive layout using Flexbox and Grid
- BEM naming convention for clean CSS structure
- Accessible design with alt text and semantic HTML
- Interactive shop buttons styled like modern e-commerce sites
- Sticky navigation header
- Optimized images using WebP format (recommended)

---

## 📄 Pages

- Home (index.html)
- About
- Shop (Products)
- Contact

---

## 🎨 Technologies Used

- HTML5
- CSS3
- Flexbox & CSS Grid
- BEM Methodology
