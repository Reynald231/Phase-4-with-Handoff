# HANDOFF REPORT – Summer Blooms

---

## 📌 Project Overview

Summer Blooms is a responsive floral shop website that showcases handcrafted fuzzy wire and satin ribbon bouquets. The design focuses on simplicity, accessibility, and a modern online shopping experience.

The website includes four pages:
- Home
- About
- Shop
- Contact
